# Popeye Trucaller Number Filter

Popeye Trucaller Number Filter by popeye marketing.

## Installation

### Windows
1. Download the latest **`.exe`** installer from the [Releases page](https://github.com/digi-bulk-marketing/6aa2cc029bc817193fce1f1f/releases/latest).
2. Run the installer and follow the prompts.
3. Launch **Popeye Trucaller Number Filter** from the Start menu.

## Updates

Download the newest installer from the [Releases page](https://github.com/digi-bulk-marketing/6aa2cc029bc817193fce1f1f/releases/latest) and reinstall.
